# Процедурная память проекта att51

## Воспроизводимое получение штатных файлов

1. Убедиться в идентичности `setup.exe` по SHA-256 `941e82cd07815861a10d7c77c9c47b94dcad799b6d7408e78bd3749d4eb2cfcc`.
2. Использовать `tools/extract_att51_5310.py` для извлечения таблиц Inno Setup 5.3.10, исходных имён, смещений и файлов.
3. Сверять исходные встроенные SHA-1 / SHA-256 с `research/inno-5.3.10-verified-files.csv` и `research/PUBLICATION_VERIFIED.md`.
4. В существующей ветке `main` готовые материалы уже находятся в `extracted/`; не нужно перепаковывать или перекодировать их без необходимости.
5. Для восстановления из пакета архивирования использовать `tools/materialize_att51_archive.py`, проверяющий ZIP SHA-256 и все 3614 SHA-256. Важное правило: для текущей ветки части `extracted/.transfer/` не требуются и удалены после успешного восстановления.
6. Не включать регистрационные сведения и непросмотренные секреты в публичный репозиторий; не запускать сторонние EXE/DLL при статическом исследовании.

## Известная ошибка и решение

Первая попытка публикации завершилась неуспешно после правильной распаковки из-за `git add ... extracted/win`: каталог пуст после исключения единственного регистрационного файла. Исправление: добавлять только реально существующие каталоги `extracted/app` и `extracted/sys`; повторный прогон #37863832729 завершился успешно.

Общую политику `repo-factory` изменять нельзя; исключение должно быть только в конфигурации `att51`.
