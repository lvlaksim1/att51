# Архитектура оригинала и исследовательского репозитория

## Репозиторий
- extracted/app/ — 3606 исходных файлов: программы, надстройки Word, MDB, шаблоны, нормативные материалы, XML/XSL и др.
- extracted/sys/ — 7 системных компонентов.
- extracted/win/ — 1 файл установки.
- research/ — первичные ведомости, источники, отчёты исследования, включая OPERATING_CYCLE.md.
- tools/ — средства распаковки и повторных проверок.
- .context/ — постоянная капсула менеджера. Manager и product authority: main.
- scripts/ и .github/workflows/ — проверка политики хранения и вспомогательные задачи восстановления файлов; не движок автономного менеджера.

Контрольный объект: setup.exe Inno Setup 5.3.10, приложение 5.1.1739, SHA-256 941e82cd07815861a10d7c77c9c47b94dcad799b6d7408e78bd3749d4eb2cfcc. Проверенное дерево extracted/: 3614 файлов, 645359024 байта.

## Устройство приложения по статическому отчёту — требуется независимая проверка отдельных вызовов
- attstart51.exe (Visual Basic 6) → запуск Microsoft Word и start51.dot → установка/подключение Attestation51.dot с основными макросами/формами.
- Пользовательская структура: база Access рабочих мест (образец model/ARMv51.MDB), организация, подразделение, рабочее место, группы аналогов, факторы и рабочие зоны.
- Создание документа: выбор протокола → шаблон Word конкретного фактора → данные измерений → специализированный макрос «Оценка условий труда».
- Фиксация: команда «Отправить в базу РМ» по отчёту изменяет/дополняет MDB, сохраняет DOC/DOCX и сопровождающий XML. Эти операции не равнозначны обычному сохранению Word.
- Итоги: карта СОУТ, сводные протоколы, ведомости и XML-экспорт через Word/VBA и XSL.

Статическое основание: research/OPERATING_CYCLE.md и оригинальные extracted/. Исполнение в Windows и реальные результаты формул пока не подтверждены; уровень «отчёт по исходному коду» не повышать до «прошло системное испытание».
