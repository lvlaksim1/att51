# Архитектура исследования

- `extracted/` — восстановленная штатная файловая структура приложения для исследования (исключение владельца от 09.10.2026). Исходные файлы отличать от преобразованных и производных.
- `research/` — проверенные статические результаты, таблицы путей, контроля целостности, документация.
- `tools/` — повторяемые средства распаковки, проверки и анализа компонентов.
- `scripts/`, `.github/workflows/`, `.gitignore` — изолированная политика хранилища `att51`: эталонная политика для всего вне `extracted/`, исключение для материалов исследования внутри него.
- `.context/` — Project Manager.

Исходный установщик Inno Setup: SHA-256 `941e82cd07815861a10d7c77c9c47b94dcad799b6d7408e78bd3749d4eb2cfcc`. Все 3614 файлов распакованы локально и проверены штатными SHA-1. Размещение файлов в GitHub сверяется отдельно.

Программные компоненты по подтверждённым признакам: Visual Basic 6, интеграция с Word/VBA, Microsoft Jet (MDB), XML/XSL и ActiveX. Доступность файлов для исследования не означает разрешения на их коммерческое использование или распространение; регистрационные и персональные данные не публикуются.
