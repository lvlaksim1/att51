# Цели проекта att51

1. Исследовать устройство приложения «Аттестация-5.1 (СОУТ)» версии 5.1.1739 на основании подлинных файлов.
2. **Выполнено:** восстановить имена, пути и содержимое из Inno Setup; сделать исходные материалы доступными в публичном репозитории для исследования (3612 файлов, кроме двух регистрационных/конфигурационных).
3. **Продолжается:** анализировать VBA, базы Microsoft Access, EXE/DLL/OCX, подготовку Word-документов, обмен XML/XSL.
4. Сохранять проверяемость выводов, контрольные суммы и происхождение материалов.
5. Соблюдать индивидуально установленную политику хранения `att51`; не менять правила других проектов.

Разработка замены приложения, внесение изменений в исходные двоичные модули и испытания запуска не являются автоматически разрешёнными задачами.
