# Цели проекта

1. Систематизировать устройство приложения «Аттестация-5.1 (СОУТ)» версии 5.1.1739.
2. Восстановить достоверную структуру установочного пакета: компоненты, файлы, штатные пути, шаблоны, зависимости.
3. Документировать и воспроизводимо исследовать исполняемые модули, обработку документов Word и форматы обмена данными.
4. Сохранить проверенные результаты в публичном `att51`, не нарушая политику хранения `repo-factory`.

Владелец пока не поручал модифицировать код исходного ПО, распространять его двоичные компоненты отдельным выпуском или разрабатывать замену.
