# Цели проекта att51

1. **[Выполнено]** Точно распаковать Inno Setup, восстановить 3614 файла и разместить их в репозитории с исходными именами, путями и контрольной проверкой.
2. **[Действует]** Установить полный цикл работы оригинальной программы: запуск, база РМ, организация, факторы, измерения, расчёт, сохранение, подготовка документов и выгрузка.
3. **[Действует]** Восстановить карту процедур VBA и Word-шаблонов, структуру Access MDB, назначение EXE/DLL/OCX и модель XML/XSL, включая пограничные сценарии.
4. **[Действует]** Доказывать каждый содержательный вывод исходным файлом, процедурой/полем, воспроизводимой проверкой и явной оценкой уверенности.
5. Соблюдать специальную политику att51 и целостность постоянного менеджера. Не затрагивать Core/фабрику и другие репозитории.
6. Не привлекать внешнюю реализацию sout-app к исследованию, пока владелец не изменит прямое указание.

**Новая самостоятельная задача одобрена владельцем 09.10.2026:** разработать внутри att51 независимый от Word и программы программный модуль формирования XML для ФГИС ФСА по оригинальным источникам/механизмам. Учитывать требования и критерии GitHub issue #2; развитие поэтапное и проверяемое. Запуск оригинальной программы и изменение оригинальных двоичных файлов по-прежнему требуют отдельного согласования.

## Подтверждённое требование владельца: Windows-приложение Att51_export
- Самостоятельное приложение с GUI и встроенным обновлением через GitHub по проверенному порядку MailRu Desktop.
- **Устанавливать строго в %ProgramData%\Att51_export**, не в Program Files. Собственные библиотеки, XSD, значок, обновления и данные — только в этой папке; системные ярлыки и стандартная регистрация удаления являются необходимыми исключениями.
- Полный установщик предлагает ярлык на рабочем столе, второй установщик обновляет действующую копию, штатное удаление очищает собственные файлы.
- Значок с надписью **EXPORT**, не XML.
- Текущий релиз v0.1.0 — диагностический, не полная генерация отчётности ФСА; развитие original VBA/XML продолжать отдельно по issue #2.
