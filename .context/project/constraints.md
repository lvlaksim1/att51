# Ограничения проекта att51

## Специальное решение владельца от 09.10.2026

**Только для репозитория `lvlaksim1/att51`** владелец разрешил помещать в Git материалы приложения, необходимые для его исследования, **без внутренних ограничений на размеры и расширения файлов**.

- Исключение применяется исключительно к каталогу `extracted/` и не изменяет правила других репозиториев или исходный `repo-factory`.
- В остальных каталогах сохраняется эталонная политика: не более 5 МиБ на файл и запрет `.exe`, `.msi`, `.zip`, `.7z`, `.rar`, `.dll`, `.pdb`.
- Реальные ограничения GitHub не отменяются: отдельный объект обычного Git размером свыше 100 МиБ GitHub не принимает. Для таких файлов потребуется отдельный согласованный способ размещения.
- По отдельным указаниям владельца от 09.10.2026 оба исходных файла `app/dop_info.ini` (102 байта) и `win/att_reg/att.reg` (41 байт) размещены в публичном репозитории. Последний файл содержит регистрационные сведения и был загружен владельцем вручную. Это индивидуальное разрешение на эти два файла, а не на публикацию любых других неизвестных учётных данных или ключей.
- Исключение из технической политики **не** является разрешением правообладателя на распространение сторонних материалов; их правовой статус должен рассматриваться отдельно.
- Не исполнять непроверенные компоненты приложения при статическом исследовании.
- Сохранять оригинальные имена и каталоги Inno Setup и сверять контрольные суммы каждого опубликованного файла.
- Явно различать подтверждённые результаты и предварительные предположения; отчёты давать на русском языке.
