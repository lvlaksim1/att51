# Ограничения проекта

- Репозиторий `att51` должен быть публичным и созданным через `repo-factory` с профилем Project Manager (проверено).
- Не включать в Git файлы крупнее 5 МиБ, `.exe`, `.msi`, `.zip`, `.7z`, `.rar`, `.dll`, `.pdb` независимо от размера. Применять эталонную политику `repo-factory`.
- Не переносить секреты и учётные данные в публичный репозиторий. Стандартные секреты при создании отключены.
- Не выполнять непроверенное ПО при статическом анализе.
- Не выдавать сигнатурное сканирование за точный перечень исходных файлов.
- Не объявлять авторские права на исследуемое стороннее приложение; отдельно проверять законность распространения его двоичных материалов.
- Объяснять наблюдения владельцу на русском языке; различать подтверждённые факты и предположения.
