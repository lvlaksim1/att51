# Идентичность проекта

**att51** — публичный исследовательский репозиторий приложения «Аттестация-5.1 (СОУТ)», версия исследуемого установщика 5.1.1739.

Создан владельцем через repo-factory с постоянным Project Manager (manager_id: project-manager). Предмет исследования — оригинальные файлы приложения, а не новая веб-реализация.

**Текущее состояние:** 3614 оригинальных файлов из setup.exe (645359024 байта) находятся непосредственно в extracted/ с сохранением штатных каталогов. Это обновляет раннюю запись, когда часть двоичных файлов ещё отсутствовала.

Репозиторий не является официальным исходным проектом правообладателя и не подтверждает лицензию на распространение. Назначение — документирование и проверяемое техническое исследование. Внешнюю переработку sout-app по решению владельца пока не использовать.
