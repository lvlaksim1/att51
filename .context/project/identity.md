# Идентичность проекта

Проект: **att51** — публичный репозиторий исследования приложения «Аттестация-5.1 (СОУТ)».

Исходная задача владельца от 09.10.2026: создать репозиторий через `repo-factory` и структурировать в нём материалы приложения из переданного `setup.exe`.

Репозиторий не является официальным выпуском программы и не содержит исходный код её разработчика. Принцип: хранить проверяемые результаты исследования и инструменты; тяжелые и запрещённые фабрикой двоичные файлы не включать в историю Git.

Источник: явное поручение владельца; проверенные сведения о репозитории и исходном установщике.
