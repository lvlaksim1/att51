# Нерешённые вопросы и риски

- Реальный запуск «Аттестация-5.1» в Windows и её поведение **не проверены**.
- Макросы VBA шаблонов Word и схемы Access (MDB) **не расшифрованы полностью**.
- Правовой статус распространения стороннего приложения необходимо учитывать отдельно от технического исключения владельца для `att51`.
- В `extracted/` намеренно не включены `app/dop_info.ini` и `win/att_reg/att.reg`; изучение программной логики по остальным 3612 файлам возможно без них.
- Нет препятствия к чтению и статическому исследованию опубликованных 3612 файлов.
