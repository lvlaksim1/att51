# Цели менеджера проекта att51

1. **[Достигнуто]** Поддерживать полный исходный комплект «Аттестации-5.1 (СОУТ)» в публичном att51: 3614 файлов, штатные пути и контрольная целостность.
2. **[Действует]** Восстановить проверяемое понимание полного рабочего цикла: запуск, выбор/создание базы РМ, организация и рабочие места, факторы, измерения, расчёты, документы и обмен данными.
3. **[Действует]** Уточнить связи Word/VBA ↔ MDB ↔ DOC/DOCX ↔ XML/XSL и зависимости EXE/DLL/OCX. Доказательства: имена процедур, пути файлов, конкретные поля и операции, результаты проверок.
4. **[Действует]** Отличать предположения, итоги статического чтения кода и подтверждённые опытами результаты. Системные испытания только по отдельному согласованию.
5. **[Действует]** Сохранять исходные файлы без преобразований, исследовательские заметки и воспроизводимые инструменты отдельно; поддерживать корректную капсулу Project Manager и индивидуальную политику att51.
6. **[Ограничение владельца]** Сторонний sout-app пока не учитывать; не переносить его гипотезы в карту оригинальной программы.

09.10.2026 владелец **поручил разработать отдельный программный модуль для формирования XML ФГИС ФСА**, работающий без Word и основной программы, но с теми же источниками данных и эквивалентными механизмами оригинала. Это отдельная новая действующая цель, **не** разрешение переписывать оригинальные двоичные файлы или выпускать готовые инсталляторы без испытаний. Учёт работ: GitHub issue #2, каталог fsa_xml_module/.

## Требования к распространению Att51_export (владелец, 09.10.2026)
- Внутри att51/desktop: GUI, иконка EXPORT, установщик Setup, обновление Update, встроенная проверка релизов GitHub, удаление.
- Место приложения строго C:\ProgramData\Att51_export; не Program Files и не собственные каталоги в AppData. Загруженные обновления — в Att51_export\updates. Системные ярлыки допускаются (необязательная галочка на рабочем столе).
- В каждом выпуске GitHub два файла и один актуальный релиз; правила MailRu Desktop перенесены с отдельным испытанием полного цикла.
- v0.1.1 опубликован на GitHub: https://github.com/lvlaksim1/att51/releases/tag/v0.1.1 . Статус GUI — диагностика, рабочая генерация ФГИС отключена до полного переноса; локальное подтверждение путей источников остаётся открытым.

## Уточнение интерфейса источников
- Для полной выгрузки протоколов из рабочей MDB не требовать указания одного XML. Внутренние XML каждого РМ определяются автоматически по `sout_factors.file` и связанным каталогам. Отдельный XML — только добровольный вход для индивидуальной диагностики.
- `fgis_ra.ini` не обязателен для чтения баз и общего списка XML. Не создавать пустой файл и не подставлять вымышленные переопределения; при отсутствии отмечать частичность сопоставлений.
- Исправленный интерфейс проверен в исходниках main, следующий бинарный выпуск только с разрешения владельца.

## Постоянный критерий сдачи изменений программы — 09.10.2026
- **Готовый результат разработки Att51_export — опубликованные установщики Setup+Update, а не только код, тесты или план.** Это безусловный критерий завершения порученной итерации приложения.
- Владелец дал постоянное разрешение на штатные выпуски последующих версий Att51_export без повторного вопроса «выпускать?». Перед отчётом о выполнении проверить GitHub Release, оба файла и успешность Windows полного цикла; дать ссылки на установщики.
- Последняя опубликованная версия после исполнения поручения — `v0.1.3`, с пакетной диагностикой XML и необязательным `fgis_ra.ini`. Разработка полной выгрузки ФСА по #2 остаётся отдельной незавершённой целью.

## Актуальный результат владельческих требований 09.10.2026
- Последний опубликованный Att51_export — [v0.1.7](https://github.com/lvlaksim1/att51/releases/tag/v0.1.7), два установщика для ProgramData/Att51_export. Установки после перехода на v0.1.7 и штатные обновления работают без администраторских прав.
- Настройки выбранных путей сохраняются только во внутреннем data/source-paths.json, переживают обновление, удаляются вместе с приложением. После Setup/Update открытие приложения предлагается отмеченным по умолчанию флажком.
- Переход со старой защищённой администраторской установки может потребовать **однократного** удаления прежней копии с прежними правами: требование неизменного ProgramData пути не позволяет обойти ACL без повышения.
- Цели независимой полной выгрузки XML ФГИС ФСА не изменились: факторы 13/14 пока не реализованы, issue #2 остаётся открытой.

## Критерий общей диагностики после решения владельца 09.10.2026
- Два отдельных текстовых отчёта по ВСЕМ рабочим местам/протоколам/факторам из MDB, а не выбор одного XML и шести поддерживаемых факторов; при отсутствии ID ФГИС **никогда не терять исходные данные протокола и никогда не придумывать ID**.
- Новый интерфейс: поля MDB организации, MDB ресурсов, необязательный fgis_ra.ini с «Авто», две кнопки текстовой выгрузки; сохранение выбранных путей и проверка обновления сохраняются. Отчёты внутри ProgramData/Att51_export/reports, только локально.
- Эта диагностическая цель реализована и отдана владельцу в [v0.1.8](https://github.com/lvlaksim1/att51/releases/tag/v0.1.8) Setup+Update. Полный XML ФГИС — отдельная активная цель #2 без ложных заявлений готовности.
