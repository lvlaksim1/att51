# Цели менеджера проекта att51

1. Поддерживать воспроизводимую исследовательскую копию файлов приложения, без добавления регистрационных сведений.
2. Выяснить архитектуру модулей приложения, способы работы с Microsoft Access (MDB), Word/VBA, XML/XSL и внешним обменом.
3. Документировать результаты с указанием доказательств, точного пути и контрольной суммы каждого исследуемого образца.
4. При технических изменениях сохранять отдельную политику `att51` и целостность капсулы менеджера.

**Уточнение на 09.10.2026:** цель восстановления и размещения 3612 безопасных файлов выполнена. Цель исследования функций и внутреннего устройства остаётся открытой.
