# Цели менеджера проекта att51

1. **[Достигнуто]** Поддерживать полный исходный комплект «Аттестации-5.1 (СОУТ)» в публичном att51: 3614 файлов, штатные пути и контрольная целостность.
2. **[Действует]** Восстановить проверяемое понимание полного рабочего цикла: запуск, выбор/создание базы РМ, организация и рабочие места, факторы, измерения, расчёты, документы и обмен данными.
3. **[Действует]** Уточнить связи Word/VBA ↔ MDB ↔ DOC/DOCX ↔ XML/XSL и зависимости EXE/DLL/OCX. Доказательства: имена процедур, пути файлов, конкретные поля и операции, результаты проверок.
4. **[Действует]** Отличать предположения, итоги статического чтения кода и подтверждённые опытами результаты. Системные испытания только по отдельному согласованию.
5. **[Действует]** Сохранять исходные файлы без преобразований, исследовательские заметки и воспроизводимые инструменты отдельно; поддерживать корректную капсулу Project Manager и индивидуальную политику att51.
6. **[Ограничение владельца]** Сторонний sout-app пока не учитывать; не переносить его гипотезы в карту оригинальной программы.

09.10.2026 владелец **поручил разработать отдельный программный модуль для формирования XML ФГИС ФСА**, работающий без Word и основной программы, но с теми же источниками данных и эквивалентными механизмами оригинала. Это отдельная новая действующая цель, **не** разрешение переписывать оригинальные двоичные файлы или выпускать готовые инсталляторы без испытаний. Учёт работ: GitHub issue #2, каталог fsa_xml_module/.
