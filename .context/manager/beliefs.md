## B6. Цепочка XML для ФГИС ФСА — статически подтверждено
- Исследован именно оригинальный экспорт для ФГИС Росаккредитации. Двухэтапная цепочка: Word-протокол → внутренний XML по РМ → выбор через таблицу sout_factors основной MDB либо docs_list.xml сводных протоколов → сопоставления ATT_DEVICE/ATT_PERSON/FGIS_RA и DIC_ND из ресурсной MDB → построение ResearchObject через v52_exp_fgis_ra2025 → сохранение fsa_prot.xml и локальная проверка fileProtocolLoad_v4.xsd. Статический источник: research/FGIS_FSA_XML_PIPELINE.md, исходные VBA в extracted/app/Attestation51.dot. Фактический запуск и загрузка в ФСА не проверены.
- Выявлено статическое расхождение: DataStatusId и ProtocolStatusId при выбранных статусах записываются с текстовыми пояснениями, тогда как fileProtocolLoad_v4.xsd требует xs:int. Это повод для воспроизводимого теста, **не** доказательство неработоспособности реальной выгрузки.
- Важно хранить рабочие res_orgs.mdb, options.ini, fgis_ra.ini и каталог *_files наряду с основной MDB. Полные сведения в research/FGIS_FSA_XML_PIPELINE.md.
