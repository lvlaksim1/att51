1. Восстановиться по .context/ENTRYPOINT.md и проверить целостность связанного состояния менеджера. Сверить GitHub main, дерево extracted/ и research/OPERATING_CYCLE.md.

4. Проследить по исходному коду цепочку вызовов: attstart51.exe → запуск Word/надстройки → база организаций/рабочих мест → выбор фактора → создание документа → ввод измерений → расчёт → «Отправить в базу РМ».

5. Отдельно составить карту MDB и справочников, переходов между окнами/формами, отчётных шаблонов и механизмов экспорта в ФГИС. Сравнения с внешним sout-app не проводить до новой директивы владельца.
6. Публиковать воспроизводимые отчёты, ссылки на оригинальные файлы и проверки в research/ и tools/. Подлинные extracted/ не менять. Перед испытаниями в Word/Windows согласовать безопасную среду и копии баз.
7. Возвращать владельцу понятную модель пользовательского цикла с разделением фактов/гипотез, перечнем открытых вопросов и следующими проверками.

Работа выполняется по доступности среды и разрешениям, без заявлений о самостоятельной непрерывной фоновой работе.
