Работа выполняется по доступности среды и разрешениям, без заявлений о самостоятельной непрерывной фоновой работе.

## Актуальный план по новой задаче владельца (приоритет)
1. **Выполнено для исходных образцов:** проверено Windows ADO/Jet OLE DB 4.0 в режиме чтения и штатный MSXML 6.0 (Actions #37868574234). Далее проверить заполненные рабочие MDB отдельно, без их изменения.
2. Воссоздать отбор протоколов и обе ветви (индивидуальные/сводные) по точным оригинальным условиям.
3. Перенести всех сопоставителей приборов, сотрудников, НД, адресов и вариантов режимов измерений из исходных VBA в независимое ядро.
4. Собрать **полный** fsa_prot.xml по исходному fileProtocolLoad_v4.xsd, проверить на минимальных и расширенных реальных/синтетических сценариях. Несовместимость DataStatusId/ProtocolStatusId решать после воспроизводимой проверки, не скрывать замену.
5. Сравнить результат с эталонным XML, сформированным самой программой на идентичных входных данных (при необходимости запросить у владельца обезличенный комплект). Только тогда заявлять о функциональной эквивалентности.
6. Подготовить пригодный для Windows способ запуска и программный интерфейс для последующего вызова из Excel/VBA; при необходимости согласовать форму выпуска.
Прогресс и приёмочные условия: issue #2, исходники fsa_xml_module/. Сторонний sout-app не использовать.
