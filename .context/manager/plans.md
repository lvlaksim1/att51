# План дальнейшего исследования att51

1. Прочитать `README.md`, `research/PUBLICATION_VERIFIED.md`, текущую капсулу и сверить доступность `extracted/app/` и `extracted/sys/`.
2. Классифицировать все MDB по именам, размеру, заголовкам Jet и структуре таблиц; отмечать параметры подключения и предполагаемую роль только после проверки.
3. Исследовать `Attestation51.dot` и другие Word-шаблоны; извлечь доказуемые модули VBA, формы и связи (если поддерживается инструментами).
4. Построить карту EXE/DLL/OCX: назначения, импортируемые библиотеки, обращения к MDB/Word/XML, регистрируемые компоненты.
5. Сопоставить XSL, XML и XSD с отчётными документами СОУТ и правилами обмена.
6. Публиковать отчёты и проверяемые средства исследования в `research/` и `tools/`; исходные файлы внутри `extracted/` не править. Для экспериментальных модификаций использовать отдельный каталог.
7. Любое испытание исполнения выполнять только при отдельном выборе подходящей контролируемой среды Windows. Не выдавать статические признаки за результаты реального запуска.
