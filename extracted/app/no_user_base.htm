Отсутствуют документы пользователя!

Для создания раздела «Документы пользователя» необходимо :

1. Создать раздел в формате WEB-страницы (*.htm).

2. Перейти в меню «АТТЕСТАЦИЯ-5.1 – Управление базой РМ - Сервис».

3. Перейти на вкладку «Расположения».

4. Указать расположение главного файла документов пользователя.

Раздел документов пользователя состоит из:

- файла главной страницы с перечнем гиперссылок на конкретные документы;

- файлов документов (НПА) в формате WEB-страницы.

 

Редактором WEB-страниц может служить MS Word.
