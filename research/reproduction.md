# Повторение исследования на локальном компьютере

Все команды выполняются на **собственной копии** установщика. Исполняемые файлы программы не запускаются и не отправляются в GitHub.

## 1. Подготовка

Поместить исходный `setup.exe` в `work/input/setup.exe`. Этот каталог находится в `.gitignore`.

Проверить контрольную сумму (Python 3):

```bash
python -c "import hashlib,pathlib; p=pathlib.Path('work/input/setup.exe'); print(hashlib.sha256(p.read_bytes()).hexdigest())"
```

Ожидаемая SHA-256 для исследованного экземпляра:

```
941e82cd07815861a10d7c77c9c47b94dcad799b6d7408e78bd3749d4eb2cfcc
```

## 2. Стандартная распаковка

На компьютере, где установлен `innoextract`, попробовать:

```bash
innoextract --extract --output-dir work/unpacked work/input/setup.exe
```

**Внимание:** данная команда не проверялась на этом экземпляре установщика, поскольку `innoextract` отсутствует в исследовательской среде. Отсутствие ошибок необходимо подтвердить отдельно.

Если распаковка прошла успешно, сформировать перечень файлов:

```bash
python tools/inventory_directory.py work/unpacked > work/unpacked-manifest.json
```

Выход содержит относительные пути, размеры, SHA-256 и признак допустимости помещения файла в историю Git по правилам фабрики.

## 3. Анализ потока распакованных данных

Для доступного локально **неструктурированного потока** распакованных данных:

```bash
python tools/scan_payload.py work/decompressed.bin > work/signatures.json
```

Опционально для **локального** выделения 32-разрядных PE-компонентов по рассчитанным границам секций:

```bash
python tools/scan_payload.py work/decompressed.bin --carve-pe work/carved > work/signatures.json
```

Выделение по сигнатурам носит исследовательский характер, а не восстанавливает исходные имена и пути файлов. Выделенные компоненты не следует запускать или публиковать без дополнительной проверки.

## 4. Публикация результатов

В GitHub помещаются только проверенные текстовые выводы и исследовательские инструменты. Размещение исходных двоичных компонентов требует отдельного решения о правомерности публикации и о способе хранения вне истории Git. Запрет фабрики на отслеживаемые `.exe`, `.dll` и архивы сохраняется.
