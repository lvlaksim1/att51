# XLS из исходных протоколов — v0.1.14 (10.10.2026)

Основание: предоставленный владельцем пример XLS и согласованные требования. Исходный бинарный XLS, частные MDB и персональные записи в репозиторий не добавляются.

## Интерфейс
Ровно две основные кнопки: «Выгрузить XML» и «Выгрузить Excel». Диагностические кнопки №1/2 удалены с экрана; их внутренние функции остались только для регрессионных проверок. Экспорт каждой кнопки запускается независимо.

## Правила XLS
- Настоящий Excel 97–2003 XLS, ровно один лист TDSheet, 26 колонок A–Z строго с заголовками оригинального образца.
- Источник: исходная рабочая ARMv51.MDB и связанные внутренние XML Document протоколов. Никаких обращений к res_orgs.mdb, подстановок ID ФГИС и внешним каталогам для Excel.
- Одна строка на показатель; K–O: название, измеренное значение, единица, методика, метод. Общие поля A–J и P–Z в первой строке протокола; в последующих они пустые, включая номер протокола.
- Несколько оригинальных значений одного поля перечисляются через «; ». Если значение не обнаружено, пишем «НЕТ ДАННЫХ»; пустые общие поля в последующих строках не заменяем.
- Ссылки nd_izm1 на нормативные документы применяются только внутри исходного Document для нахождения текстовых названий методик; числовые номера nd и записи вида ||id N|| в Excel не выгружаются. В отличие от ID ФГИС, исходные номера протоколов, ИНН, заводские номера приборов являются допустимыми фактическими сведениями.
- Если одного из исходных внутренних XML не хватает, выгрузка прерывается с пояснением, без создания частичного файла.
- Создание файла настоящего формата XLS — через установленный Microsoft Excel и COM. Запись во временный XLS с последующей атомарной заменой в ProgramData/Att51_export/reports.

## COM и проверка
Фоновая операция XML и Excel обёрнута в pythoncom.CoInitialize/CoUninitialize в одном и том же потоке. Windows-испытание новой версии вызывает --self-test-mdb-thread на установленном приложении до других отчётов, чтобы выявлять CO_E_NOTINITIALIZED (-2147221008).

Проверки desktop/tests/test_excel_export.py: 26 колонок, несколько показателей, отсутствие ID, заполнение НЕТ ДАННЫХ, отсутствие повторов общих сведений, незаполненный исходный XML, самостоятельность от ресурсов ФГИС, освобождение COM. Дополнительные проверки на фактических внутренних XML владельца и приём порталом ФГИС **ещё не проводились**.
