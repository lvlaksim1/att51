# Проверенная распаковка Inno Setup 5.3.10

Дата исследования: 2026-10-09. Установщик: **«Аттестация-5.1 (СОУТ)» 5.1.1739**.

## Результат

Распаковка произведена **без запуска** `setup.exe` и без выполнения кода из извлечённых файлов. Поскольку установка `innoextract` из текущей рабочей среды была недоступна, применён собственный ограниченный разборщик формата Inno Setup 5.3.10, реализованный по документированным структурам свободного проекта [innoextract](https://github.com/dscharrer/innoextract).

Проверены CRC32 служебных блоков, восстановлены две таблицы Inno Setup, распакован LZMA1-поток и выполнено обратное преобразование x86 CALL/JMP для 14 файлов.

## Самостоятельное повторение

Рядом с законно полученным исходным установщиком выполнить:

```shell
python tools/extract_att51_5310.py setup.exe work/att51-extracted
```

Для формирования только ведомости и контрольных сумм (без записи 3 614 файлов):

```shell
python tools/extract_att51_5310.py setup.exe work/att51-meta --metadata-only
```

Используется стандартная библиотека Python, установка сторонних модулей не нужна. Извлечённые данные хранятся локально, **не публикуются автоматически**.

## Границы проверки

1. Все **3 614 штатных записей файлов** распакованы и подтверждены их встроенными SHA-1.
2. Восстановлены имена, относительные пути и размер каждого файла; не выполнялись инсталлятор, регистрация библиотек или код Word/VBA.
3. **Статическая распаковка не доказывает** корректную работу приложения после установки в Windows.
4. Не определены отношения между всеми модулями, форматы всех баз, макросы всех шаблонов и особенности лицензирования.
5. Двоичные файлы принадлежат правообладателям ПО. Репозиторий публикует лишь исследовательский перечень и инструменты, **не** целиком стороннюю программу.
