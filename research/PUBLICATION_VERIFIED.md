## Способ восстановления

Изначально из исходного `setup.exe` получены две таблицы Inno Setup и извлечены файлы в отдельные штатные каталоги. Архив исходного дерева разбит на 34 части, загруженные как двоичные Git-объекты, далее GitHub Actions восстановил ZIP, проверил его SHA-256 и SHA-256 каждого файла согласно ведомости внутри ZIP, записал оригинальные байты в `extracted/` и удалил временные части из текущей версии репозитория.

Код проверки — `tools/materialize_att51_archive.py`. В Git-истории остаётся коммит с временными частями архива; в текущей версии они отсутствуют.

Оговорка: ни одна из этих операций не является доказательством работоспособности Windows-приложения или отсутствия неизвестных дефектов его кода.
