# att51 — исследование приложения «Аттестация-5.1 (СОУТ)»

## Индивидуальное исключение на исследовательские файлы

**09.10.2026 владелец разрешил для одного репозитория `att51` размещать файлы приложения без лимита 5 МиБ и без запрета на исполняемые расширения, строго внутри `extracted/`.** Репозиторий `repo-factory` и ограничения остальных проектов не изменялись. Для известных потенциально чувствительных файлов действует запрет публикации.

Проверены и уже доступны в GitHub **14 оригинальных исполняемых компонентов** (7 EXE, 2 DLL, 5 OCX): [`extracted/app/`](extracted/app/) и [`extracted/sys/`](extracted/sys/). Их размеры и содержимое сверены по исходным данным установщика. [Подтверждённый коммит](https://github.com/lvlaksim1/att51/commit/e01127b6ff6481c9e969cad9989314e39cc37099).

**Статус публикации:** 458 исходных текстовых ресурсов + 14 исполняемых файлов. Это пока **не все 3614 файлов**. Например, `DataBase.mdb` размером 10 477 568 байт не загружен: передача через текущий канал GitHub завершилась ошибкой соединения. Объём файла в пределах возможностей обычного GitHub; этот сбой не связан с политикой хранения.

## Исходные текстовые ресурсы (доступны непосредственно в GitHub)

В каталоге [**extracted/**](extracted/) опубликованы **458 самостоятельных текстовых файлов** с сохранением дерева установки: **441 XSL-преобразование**, **5 XML-файлов**, **4 XSD-схемы**, **3 CSS**, **2 HTML**, **2 INI** и **1 JavaScript**. Это позволяет исследовать правила формирования отчётов, обмена данными, интерфейсные компоненты и настройки непосредственно в GitHub.

**455 файлов совпадают побайтово с установщиком.** Ещё **3 файла** из Windows-1251 переведены в UTF-8 для правильного отображения кириллицы: `app/options.ini`, `app/html/data/api/dtree.js`, `app/html/data/api/dtree.css`. Для всех 458 опубликованных ресурсов сохранены контрольные суммы оригинала и опубликованной версии в [ведомости переносов](research/published-text-files.csv).

**Публикация исходных файлов продолжается по индивидуальному исключению владельца для att51 от 09.10.2026.** Это пока не полная публикация 3614 установочных файлов. Все оригинальные имена и пути доступны в [полной ведомости](research/inno-5.3.10-verified-files.csv), а двоичные файлы, базы, макросы Word и документы можно восстановить локально [проверенным распаковщиком](tools/extract_att51_5310.py) из исходного `setup.exe`. Остаются вне публичного хранилища большая часть MDB, DOC, DOT, изображений, нормативных документов из `NPA5/` и прочие ещё не переданные материалы; 14 исполняемых компонентов уже опубликованы.
- `win/att_reg/att.reg` (содержит возможный регистрационный номер) и `app/dop_info.ini` (неизвестное назначение, не публикуется до анализа).

Исходные файлы приложения принадлежат соответствующим правообладателям. Их размещение здесь служит техническому исследованию, не означает передачу прав на распространение.

Публичный исследовательский репозиторий приложения версии **5.1.1739**, созданный через [repo-factory](https://github.com/lvlaksim1/repo-factory/issues/188) с профилем Project Manager.

Для 14 исполняемых компонентов отменено дополнительное преобразование адресов инструкций x86.

## Повторение исследования

На локальном компьютере с Python 3:

```shell
python tools/extract_att51_5310.py setup.exe work/att51-extracted
```

Для записи только перечня без отдельных распакованных файлов:

```shell
python tools/extract_att51_5310.py setup.exe work/att51-meta --metadata-only
```

Скрипт проверяет исходный SHA‑256, читает таблицы Inno и проверяет контрольные суммы файлов.

## Правила размещения и ограничения

По решению владельца от 09.10.2026 в **этом одном репозитории** допускаются любые исследовательские материалы в каталоге `extracted/` независимо от расширения и локально установленного предела размера. Вне него сохраняется [политика repo-factory](https://github.com/lvlaksim1/repo-factory/tree/main/policy/repository-storage). Стандартный GitHub не принимает отдельные файлы более 100 МиБ; это внешний предел, который исключение не отменяет. Из публикации исключены известные регистрационные данные и непроверенные конфигурации. Правообладателям приложения и шаблонов принадлежат соответствующие права; публикация исследовательской ведомости не означает публикации коммерческой программы.

**Точная распаковка доказана проверкой SHA‑1**, но работа программы после установки в Windows не проверялась. Извлечение VBA-модулей, анализ схем баз данных и функций приложения — отдельные дальнейшие задачи, отражённые в [задаче №1](https://github.com/lvlaksim1/att51/issues/1).
