# att51 — исследование приложения «Аттестация-5.1 (СОУТ)»

Публичный исследовательский репозиторий приложения версии **5.1.1739**. Создан через [repo-factory](https://github.com/lvlaksim1/repo-factory/issues/188) с постоянной капсулой Project Manager.

## Исходные файлы доступны непосредственно в GitHub

**[Открыть распакованное приложение — `extracted/`](extracted/)**

В исходных каталогах `extracted/app/` и `extracted/sys/` опубликовано **3613 оригинальных файлов общим объёмом 645358983 байта**. Форматы включают EXE, DLL, OCX, MDB, Word DOT/DOC, XML/XSL, HTML, графику, шаблоны и другие ресурсы. Исходные имена и относительные пути сохранены; содержимое файлов не преобразовывалось.

В установщике было **3614 файлов**. Из публикации исключён только `win/att_reg/att.reg` (**41 байт**, регистрационный номер). Файл `app/dop_info.ini` (**102 байта**) опубликован в оригинальном виде по указанию владельца для исследования его назначения. Полная [проверенная исходная ведомость](research/inno-5.3.10-verified-files.csv) содержит все 3614 записей без секретных значений.

- `research/` и `tools/` — отчёты и проверяемые инструменты.
