Исходный установщик `setup.exe` (54 872 144 байта, SHA‑256 `941e82cd07815861a10d7c77c9c47b94dcad799b6d7408e78bd3749d4eb2cfcc`) содержит служебные таблицы **Inno Setup 5.3.10**. Все **3 614 файла** восстановлены с исходными именами и путями назначения. Общий размер распакованного содержимого **645 359 024 байта**; **3 614 из 3 614** встроенных контрольных сумм SHA‑1 совпали. Для 14 исполняемых компонентов отменено дополнительное преобразование адресов инструкций x86.

## Повторение исследования

На локальном компьютере с Python 3:

```shell
python tools/extract_att51_5310.py setup.exe work/att51-extracted
```

Для записи только перечня без отдельных распакованных файлов:

```shell
python tools/extract_att51_5310.py setup.exe work/att51-meta --metadata-only
```

Скрипт проверяет исходный SHA‑256, читает таблицы Inno и проверяет контрольные суммы файлов.

## Правила размещения и ограничения

В истории GitHub **не хранятся** установщик, исполняемые файлы, библиотеки, архивы и файлы более 5 МиБ. Это соответствует [политике repo-factory](https://github.com/lvlaksim1/repo-factory/tree/main/policy/repository-storage). Правообладателям приложения и шаблонов принадлежат соответствующие права; публикация исследовательской ведомости не означает публикации коммерческой программы.

**Точная распаковка доказана проверкой SHA‑1**, но работа программы после установки в Windows не проверялась. Извлечение VBA-модулей, анализ схем баз данных и функций приложения — отдельные дальнейшие задачи, отражённые в [задаче №1](https://github.com/lvlaksim1/att51/issues/1).
