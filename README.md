# att51 — исследование приложения «Аттестация-5.1 (СОУТ)»

Публичный исследовательский репозиторий для изучения полученного установщика приложения «Аттестация-5.1 (СОУТ)».

**Исследуемый экземпляр:** версия `5.1.1739`, исходный файл `setup.exe` (54 872 144 байта), SHA-256 `941e82cd07815861a10d7c77c9c47b94dcad799b6d7408e78bd3749d4eb2cfcc`.

## Состояние

- Репозиторий создан через [repo-factory](https://github.com/lvlaksim1/repo-factory/issues/188) с профилем Project Manager.
- Выполнено статическое исследование установщика Inno Setup. Исполняемый код **не запускался**.
- Выявлены компоненты Win32/Visual Basic 6, упоминания Microsoft Jet, шаблонов Word и обмена XML.
- Доступен [проверяемый перечень находок](research/components.md), [карта образцов документов](research/word-templates.md) и [инструмент сканирования](tools/scan_payload.py).
- **Важно:** это пока не полный каталог штатных файлов установки. Присутствующие сигнатуры не равнозначны отдельным файлам.

## Двоичные компоненты и права

Исходный `setup.exe`, содержимое установочного пакета, `.exe`, `.dll` и другие тяжёлые двоичные объекты **не публикуются в истории Git**: это запрещено принятой [политикой repo-factory](https://github.com/lvlaksim1/repo-factory/tree/main/policy/repository-storage). Данный репозиторий не представляет исходный код разработчика программы и не объявляет никаких прав на ПО третьих лиц.

Для исследования на локальном компьютере поместите полученный законным способом `setup.exe` в каталог `work/input/` (он исключён из Git). Ничего из этого каталога автоматически в GitHub не отправляется. Для штатной распаковки Inno Setup можно воспользоваться `innoextract` в локальной среде и затем сформировать перечень файлов инструментом `tools/inventory_directory.py`. Исследование осуществляется без исполнения программы.

## Подтверждённые признаки

- Установщик: Inno Setup, Win32.
- Внутри потока распакованных данных найдены 11 структурно корректных заголовков PE32 и 675 сигнатур составных документов OLE. Это **количество сигнатур**, а не официальная ведомость установленных файлов.
- У ряда PE32 импортируется `MSVBVM60.DLL`; среди других зависимостей — `JetCmpEr.DLL`, `MSJTER40.DLL`, `VBAJET32.dll`.
- Обнаружены строковые упоминания `Attestation51.dot`, `AttestationReport.xml`, `AttestationReport.zip`.

## Ограничения

Пока не восстановлены исходная таблица файлов Inno Setup, точные штатные пути каждого файла и взаимосвязь всех шаблонов. Все выводы, требующие исполнения приложения в Windows, остаются непроверенными. Не следует использовать сканирование сигнатур как доказательство присутствия исполнимого файла в конкретном каталоге установки.
