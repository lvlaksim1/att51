# Att51_export — приложение для Windows

**Состояние: диагностическая версия.** Исходные базы, протоколы и справочники «Аттестации-5.1» читаются без Word. Полный XML для ФГИС ФСА пока не готов — в программе нет кнопки выдачи рабочего `fsa_prot.xml`.

## Строгие правила установки

- Папка установки: **`%ProgramData%\Att51_export`** (обычно `C:\ProgramData\Att51_export`), а не `Program Files`.
- Исполняемый файл, зависимости, XSD, значок и загруженные обновления хранятся только внутри `Att51_export`. При работе приложение не создаёт отдельные журналы или настройки в профиле пользователя.
- Исходные MDB/XML/INI могут находиться в других папках, но **не копируются и не изменяются**. Они используются только для чтения по указанным пользователем путям.
- В каждом релизе GitHub: `Att51_export_Setup_vX.Y.Z.exe` — первая установка; `Att51_export_Update_vX.Y.Z.exe` — обновление установленной программы.
- Полный установщик предлагает необязательный ярлык на рабочем столе и создаёт пункт меню «Пуск». Ярлыки и стандартная системная регистрация установленной программы — исключения, необходимые самой Windows.
- Приложение самостоятельно проверяет последний выпуск GitHub. При наличии новой версии сверяет SHA-256 и размер файла, запрашивает повышение прав только для обновления, скачивает файл в `Att51_export\updates` и запускает установщик. Если контрольная сумма GitHub отсутствует, автоматическое обновление не запускается.
- Удаление: «Установленные приложения» Windows либо `%ProgramData%\Att51_export\unins000.exe`; вместе с приложением удаляются собственные файлы обновления, а рабочие базы пользователя не затрагиваются.
- Значок программы, ярлыка и установщика: документ с зелёной стрелкой и словом **EXPORT** — без надписи XML.

## Обнаружение исходных файлов (задача № 8)

Начиная со следующей версии приложение проверяет только подтверждённые каталоги оригинальной «Аттестации-5.1» внутри `Program Files` / `Program Files (x86)`, а также путь из переменной `ATT51_ORIGINAL_DIR`, если она явно задана. Оригинальная установка распознаётся по наличию **обоих** файлов `Attestation51.dot` и `options.ini`. Произвольные каталоги пользователя и диски не сканируются.

- Рабочая база определяется по `[DB] sout_path` в оригинальном `options.ini`. Если значение указывает на каталог с несколькими MDB, необходим явный выбор.
- Ресурсная база выбирается по `[DB_res] res_flag/res_path`; при `res_flag=1` недоступный внешний файл **нельзя** заменять локальным. При локальном режиме допускается лишь файл `res_orgs.mdb` подтверждённой оригинальной установки.
- Параметры `fgis_ra.ini` ищутся в подтверждённой исходной установке, не в каталоге Att51_export.
- Кнопка «Выбрать XML протокола…» читает список `sout_factors.file` из выбранной рабочей MDB **без записи**, ограничивает выбор номером РМ (если заполнен) и показывает только реально существующие XML в каталоге `<имя MDB>_files`. При нескольких XML пользователь выбирает нужный.
- Если оригинальное приложение находится в другом каталоге, доступна кнопка «Указать папку Аттестации…». Остаются доступными все четыре поля ручного выбора. Данные не копируются и не изменяются, найденные пути не записываются в настройки приложения.

Важно: обнаружение файла не доказывает актуальность его содержимого и соответствие рабочей базе. Достоверность экспорта в ФГИС пока не установлена; кнопка полноценной выгрузки остаётся недоступной.

## Сборка и проверки

Windows, **32-разрядный Python 3.11** для совместимости с Jet OLE DB 4.0, Inno Setup 6:

```powershell
python -m pip install -r desktop/requirements-build.txt
./desktop/build.ps1 -Version 0.1.0
```

Проверить тесты: `python -m unittest discover -s desktop/tests -v`.

Рабочий процесс выпуска — `Att51_export Windows Release` в GitHub Actions. Его можно запустить вручную с номером версии или открыть от имени владельца задачу с заголовком `[ATT51_BUILD_RELEASE]` и телом `{"version":"0.1.0"}`. Перед публикацией выполняются автоматические испытания, сборка приложения и обоих установщиков, пробная установка/обновление/удаление на Windows. После создания релиза удаляются старые выпуски, сохраняя только последний.

**До проверки на заполненной рабочей базе и сравнения с оригинальным экспортёром функционал создания полного XML остаётся заблокированным.**
